# Mentecobre 0.1.0

## Introduction
This projects build a web (using spa and api) designed to organize the Coppermind translation
to Spanish. 

## AI usage

AI is used **only for planning and testing**. It is not used to write the
implementation: the code is written by hand.

Only open-source, free-of-charge AI models are used for planning and testing.
No paid or proprietary model APIs are involved.

- **Planning**: issues are written by hand on GitHub; an AI reads them and helps
  break the work down. See `docs/agents/issue-tracker.md`.
- **Testing**: AI assists with test design and review.
